mmux vs Codex app

mmux is a terminal multiplexer that keeps any CLI coding agent, shell and dev server running in a persistent, per-directory tmux session. OpenAI's Codex app, launched in February 2026 and part of the ChatGPT desktop app since July 2026, is a graphical command center for parallel Codex chats in git worktrees. Both run agents side by side in worktrees; they differ in where they live (a terminal on any machine vs a desktop window) and in which agents they run (any CLI vs Codex).

Last checked against OpenAI's Codex app documentation (ChatGPT desktop app, Codex CLI 0.162.1) on 2026-10-14.

// tl;dr

Pick the Codex app if you work with Codex on a desktop and want a graphical review loop: inline comments on diffs, chunk-level staging, pull requests and PR review without leaving the app, plus cloud tasks, scheduled tasks and a native Windows build.

Pick mmux if you run several different agent CLIs (Claude, Codex, Gemini and others) and want them, your shells and your dev servers in one terminal UI that keeps running on a laptop or a remote server after you close the terminal or lose SSH.

They also combine: the Codex CLI is a built-in mmux agent preset, and the desktop app can open the same repository for review.

What is the Codex app?

OpenAI released the Codex app for macOS in February 2026 as a place to run several Codex agents in parallel, each in its own chat, organized by project [13]. On July 9, 2026, OpenAI shipped a new ChatGPT desktop app for macOS and Windows that combines Chat, Work and Codex; existing Codex app users move to it by updating [12]. OpenAI's documentation now describes these features under the ChatGPT desktop app [1], with a Windows build from the Microsoft Store [10] and a Linux build in preview for Ubuntu, Debian, Fedora and Arch [11]. This page keeps calling it the Codex app, since that is the part being compared.

A Codex project points at a local folder (or several, with one primary repository) or at a project on an SSH host [8][5]. Each chat can run in the local checkout or in a managed git worktree that Codex creates under $CODEX_HOME/worktrees; Handoff moves a chat and its code between the two, and Codex removes old managed worktrees beyond the 15 most recent after saving a snapshot [2]. Each chat has an integrated terminal scoped to its project or worktree [4], and the review pane shows the diff, takes inline comments for Codex, stages or reverts chunks, commits, pushes and opens pull requests [3]. The app also offers scheduled tasks [6], cloud tasks, notifications when a turn finishes or needs approval [7], and sign-in with a ChatGPT plan or an API key [9].

Where the Codex app is better

  • The review loop. You can comment on a diff line and have Codex address it, stage or revert individual chunks, open a pull request and review PRs in a side panel [3][12]. mmux's git panel stages whole files or directories, has no inline comments and does not create pull requests.
  • Worktrees with a safety net. Codex snapshots a managed worktree before deleting it and restores it when you reopen the chat, and Handoff moves work between the worktree and your local checkout [2]. mmux removes only finished worktrees whose commits are merged or pushed, but has no snapshot or handoff.
  • Work beyond your machine. Codex cloud tasks run in OpenAI's environments, scheduled tasks start chats on a timer [6], and the ChatGPT mobile app can drive a connected Mac or Windows host [5]. mmux runs only where you start it and schedules commits, not agent runs.
  • Windows and no terminal required. There is a native Windows app with a Windows sandbox and optional WSL [10], and the whole interface is a desktop GUI. mmux is a TUI for macOS and Linux that needs tmux.
  • Built-in sandboxing. The app ships its own sandbox and approval modes (a native Windows sandbox, and bubblewrap when the agent runs in WSL2) [10]. mmux does not sandbox; it starts each agent with that agent's own permission flags.

Where mmux is better

  • Any agent, side by side. mmux ships presets for Claude, Codex, Gemini, Amp, opencode, Pi and Grok, and any other command can be an agent. A Claude agent and a Codex agent can work in two worktrees of the same repository in one sidebar, each row turning green when it is done.
  • Survives the window and the connection. The TUI runs inside an invisible per-directory tmux session, so closing the terminal or dropping SSH only detaches; mmux attach rejoins from anywhere. After a quit or crash, Claude, Codex, Pi and Grok agents resume their conversations.
  • Lives where the code lives. Run mmux on a remote dev box and it keeps working there with nothing attached; under 60 columns it switches to a single-column layout for SSH from a phone, and desktop notifications travel over SSH to the machine your terminal runs on.
  • Dev servers as first-class rows. Processes sit in the sidebar with start, stop and a stop: teardown command. Only one checkout of a repository runs a given process at a time, so starting Dev in a worktree stops it in the main clone first and localhost:3000 is always the branch you last started.
  • Scriptable by agents. Every running mmux has a control socket: mmux ask, mmux wait, mmux read and mmux worktree new --prompt let one agent start, prompt and read another, visibly in your sidebar.
  • Open source, no account. mmux is GPLv3, a single binary, and needs no sign-in of its own.

When to use which

Choose the Codex app when

  • Codex is your only agent and you have a ChatGPT plan.
  • You review agent work line by line and want PRs opened from the same window.
  • You want tasks to run in the cloud or on a schedule.
  • You are on Windows, or you prefer a GUI to a terminal.

Choose mmux when

  • You mix agents from different vendors on the same repository.
  • Your agents run on a remote server you reach over SSH, sometimes from a phone.
  • Dev servers, shells and agents should live in one persistent session that outlasts the terminal.
  • You want scripts or agents to start, prompt and wait for other agents.

Using the Codex app and mmux together

  1. Turn on the Codex preset in mmux with mmux agents (or a in the sidebar), picking the normal, auto or danger mode.
  2. Start Codex in its own worktree, from the TUI with w or from a script.
  3. When you want the Codex app's review pane or a pull request, add the repository as a local project in the desktop app and review there; mmux's git panel picks up commits made elsewhere on its own.
mmux worktree new fix-auth --agent codex --prompt "fix the login bug"
mmux ask --agent codex "why does /health 500?"

FAQ

Is the Codex app still a separate app?

No. OpenAI launched the Codex app for macOS in February 2026 and, on July 9, 2026, released a new ChatGPT desktop app for macOS and Windows that combines Chat, Work and Codex. OpenAI's release note says Codex app users move to it by updating as usual. The Codex features (projects, parallel chats, worktrees, the review pane) live on inside it, and OpenAI's docs now call it the ChatGPT desktop app.

Can mmux run OpenAI Codex?

Yes, the Codex CLI. Codex is one of mmux's built-in agent presets, with normal, auto and danger launch modes. mmux shows when a Codex agent is working or ready, resumes its conversation when you reopen a directory, and mmux last reads its reply from the Codex transcript. It does not run the ChatGPT desktop app itself, which is a graphical program.

Can the Codex app run Claude Code or other agents?

OpenAI's docs describe the app running Codex with OpenAI's models and do not describe launching other vendors' agents as chats. Each chat has an integrated terminal, so you can start any CLI there, but the app does not track it as an agent. mmux treats Claude, Codex, Gemini, Amp, opencode, Pi, Grok or any other command as an agent in the same sidebar.

Do agents keep running when I close the window?

In mmux, yes: closing the terminal or dropping SSH only detaches, and everything keeps running in an invisible tmux session until you reattach. For the Codex app, OpenAI's docs say scheduled tasks need the computer on and the app running, and remote access stops when the host closes the app. Codex cloud tasks run on OpenAI's servers instead.

What do they cost?

mmux is free and GPLv3 licensed; each agent you run is billed by its own provider. Codex in the ChatGPT desktop app is included in ChatGPT plans: Free at $0, Go at $8, Plus at $20, Pro from $100 per month, and Business at $20 per user per month billed annually, per OpenAI's pricing page in October 2026. It also works with an API key billed at API rates, without cloud features.
